# Label Studio OpenSpec

This directory is the independent planning and specification home for the
`Pein2017/label-studio` fork. Label Studio changes, historical refinement
contracts, and their verification records belong here rather than in the
parent CoordExp repository.

The parent `/data/CoordExp/openspec` remains the home for CoordExp data,
inference, training, and native-runtime contracts. The two OpenSpec roots are
intentionally separate Git histories.
